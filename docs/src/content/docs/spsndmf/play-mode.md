Unity のプレイモードに入ると、SPS for NDMF はシーンにある Plug / Socket を組み立てて、その場で動く状態にします。アップロードしなくても、エディタ上で見た目や当たり方を確かめられます。

## アバターの外に置いたものも動きます

アバターに付けた Plug / Socket はもちろん、**アバターの外**（シーンに直接置いたオブジェクトなど）に付けた Plug / Socket も、プレイモード中は同じように組み立てられます。小物やギミック単体で試したいときに使えます。

プレイモードを抜けると、組み立てられたものは消えて元の状態に戻ります。シーンに何かが残ることはありません。
