Unity のプレイモードに入ると、SPS for NDMF はシーンにある Plug / Socket を組み立てて、その場で動く状態にします。アップロードしなくても、エディタ上で見た目や当たり方を確かめられます。

## アバターの外に置いたものも動きます

アバターに付けた Plug / Socket はもちろん、**アバターの外**（シーンに直接置いたオブジェクトなど）に付けた Plug / Socket も、プレイモード中は同じように組み立てられます。小物やギミック単体で試したいときに使えます。

プレイモードを抜けると、組み立てられたものは消えて元の状態に戻ります。シーンに何かが残ることはありません。

## コンタクトの設定

VRChat のコンタクトは、本来プレイモードでは互いに反応しません。そのままでは SPS も動かないため、SPS for NDMF はプレイモードの間だけ、**すべてのコンタクトが互いに反応する**ように切り替えています。この設定は最初から有効になっています。

- メニュー: **Tools → SPSNDMF → Settings → Enable SPS contacts in play mode**

### 知っておいてほしいこと

この切り替えはエディタ全体に効くため、次のような影響があります。

- コンタクトの「自分」「他人」の区別が、プレイモード中は無くなります
- SPS とは関係のないコンタクト（他のギミックなど）にも同じ影響が出ます

プレイモードで SPS 以外のコンタクトが思った通りに動かないときは、この設定が原因かもしれません。上のメニューからオフにすると、VRChat 本来の挙動に戻ります（そのかわり、プレイモードで SPS は反応しなくなります）。

なお、有効な状態でアバターのビルドが走ると、NDMF Console にお知らせが表示されます。エラーではないので、そのままビルドは続きます。
