SPSNDMF には、アバター内の DPS / TPS をビルド時にアップグレードする挙動があります（VRCFury 由来の機能で、元の名前は "Auto-Upgrade DPS with contacts"）。ただし「アップグレード」という名前から想像されるような書き換えは行いません。**DPS / TPS のマテリアル・シェーダー・ライト・アニメーションはそのまま残り、ビルド時に接触判定用の Contacts が追加されるだけ**です。

DPS や TPS をそのまま使い続けたい場合も、特別な設定は不要です。

## いつ動くか

アバターに SPS の **Plug または Socket が1つでもある**ときだけ動きます。SPS コンポーネントが1つも無いアバターでは、DPS / TPS があっても何もしません。

この挙動はオフにできません。

## 何が追加されるか

ビルド時のアバターに対して、次の部位に **Sender Contacts** が追加されます。相手の SPS が「ここに Plug / Socket がある」と検出するためのもので、他のアバターの SPS 触覚通知やアニメーションを反応させられるようになります。

- **DPS / TPS のマテリアルが付いた Renderer** — Plug 相当の Sender
- **DPS のライト（Hole / Ring）を持つオブジェクト** — Socket 相当の Sender

追加されるのは Sender だけです。次のものは付きません。

- SPS の変形（シェーダーの差し替えやメッシュの加工）
- SPS メニューの項目
- [OGB Haptics](/spsndmf/ogb-haptics/) 用の受信部品

## 変更されないもの

- DPS / TPS のマテリアルとシェーダー
- DPS のライト（削除も移動もされません）
- DPS / TPS 用のアニメーターレイヤーやパラメータ

## 注意: TPS の Sender は置き換わる

TPS が自前で持っている Sender Contacts（`TPS_Pen_Penetrator` などのタグを持つもの）は削除され、SPS が生成する同等の Sender に置き換わります。通常の TPS の使い方であれば動作は変わりませんが、TPS 純正の Sender を直接参照するギミックがある場合は影響を受けます。

## 参考: 手動アップグレードとの違い

**Tools → SPSNDMF → SPS → Upgrade DPS to SPS** にある手動のアップグレードは、これとは別物です。こちらは選択中のアバターの DPS / TPS 構成を SPS の Plug / Socket コンポーネントに置き換え、古いライト・アニメーターレイヤー・パラメータ・アセットを削除する、シーン上のアバターを実際に書き換える操作です。実行前に変更内容の一覧が表示され、確認してから適用できます。ビルド時アップグレードではこれらの書き換えは行われません。
