Scene ビューでは、Socket と Plug の位置や大きさが線や矢印（ギズモ）で表示されます。

## 既定の表示

既定では、**選択しているオブジェクトとその子にある Socket / Plug だけ**を表示します。何も選択していないときや、別のオブジェクトを選択しているときは表示しません。

アバター全体の Socket / Plug を見たいときは、アバターのルートを選択してください。

## 常に表示する

**Tools → SPSNDMF → Settings → Show SPS Gizmos Only When Selected** のチェックを外すと、VRCFury と同じく、選択していなくても常に表示します。常に表示しているときは、Scene ビューのギズモをクリックして、その Socket / Plug を選択することもできます。

これは Unity エディタ（PC）全体の設定で、アバターには保存されません。VRCFury Stub の **Tools → VRCFury Stub → Settings** にある同じ項目とも連動します。
