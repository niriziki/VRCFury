OGB Haptics は、Plug / Socket の接触や挿入を、PC 上の OSC 触覚アプリ（OSCGoesBrrr など）に伝えるための仕組みです。触覚デバイスを使わないなら、この機能を切っても SPS の動作は変わりません。

## 設定の場所

**Tools → SPSNDMF → Settings → Enable SPS Haptics** で切り替えます。既定ではオンです。

これは Unity エディタ（PC）全体の設定で、アバターには保存されません。Socket / Plug のインスペクターにある **Enable OGB Haptics** はこの設定の表示だけで、そこからは変更できません。

同じ PC でビルドするすべてのアバターの、Socket と Plug の両方に効きます。

## オフにすると何が起こるか

ビルド時に、触覚アプリ向けの部品が作られなくなります。

- Socket あたり 4〜11 個、Plug あたり 8 個の **Contact Receiver**（`OGB/Orf/…`・`OGB/Pen/…` というパラメータで値を出すもの）
- 触覚アプリがアバターを見つけるためのパラメータ（`OGB_ENABLED`・`VFH/Version/…`）

これらは自分の PC の触覚アプリだけが読むもので、SPS の他の機能はどれも使っていません。ふだんのプレイでは触覚アプリを起動している間しか有効にならない部品なので、オフにしても見た目や動作は変わりません。

## オフにしても変わらないこと

- Plug の変形（SPS1 の点光源、SPS2 の画面マーカー）
- 位置ビーコン（Sender）。相手のアバターがこちらの Plug / Socket を検出する仕組みはそのまま残ります
- Depth Animations、Active Animation、Hand touch zone
- メニューのトグルと Auto 選択

**相手側には一切影響しません。** 自分の触覚デバイスへの出力が止まるだけで、相手の Socket / Plug の反応は変わりません。

## いつオフにするか

OSC 触覚アプリを使わないなら、オフにしても失うものはありません。Contacts の数が減るので、上限に近いアバターでは余裕ができます。

後で触覚アプリを使いたくなったら、設定を戻してビルドし直してください。設定はアバターに残らないため、ビルドした PC の設定がそのまま反映されます。
